# Art direction and reference literacy

Use [judgment](judgment.md) as the decision foundation. Read real brand material before constructing a new identity. Existing approved type, colors and components constrain the solution; a request for polish does not automatically authorize replacing them.

## Make the direction observable

Translate a mood into a grammar: composition, type roles, image treatment, palette roles, density, shape, material and movement. For “quiet precision,” possible decisions include aligned numeric columns, a restrained emphasis range, direct status language and immediate state feedback. For “warm hospitality,” editorial photography and gracious spacing may fit a public site while the reservation form stays compact and explicit. These are hypotheses tied to a brief, not industry-to-style lookup rules.

Write a thesis and identify its distinctive move. The supporting system should reinforce it. Avoid stacking unrelated effects because they each look impressive. A distinctive image treatment with ordinary navigation often communicates more clearly than unusual navigation, animated type and a 3D cursor together.

## Study references as relationships

Record the source, viewport and state. Describe the reading sequence, dominant proportions, alignment, type contrast, content density, image crop and interaction cues. Separate what is visible from what you infer. A screenshot cannot reveal loading behavior, keyboard order or the original font license. If only one viewport is supplied, devise responsive behavior and label it as an implementation decision.

Extract a principle rather than a whole identity: for example, “a large artifact establishes subject before introductory copy.” Adapt it to original content. Preserve rights and attribution for any actual reused assets or code. A reference does not authorize redistribution of a proprietary font or logo.

## Explore for a reason

When the brief leaves meaningful freedom, compare a small number of materially different approaches using the same task and content. A useful contrast might be an image-led narrative versus a specimen-led typographic catalog. Changing accent colors on the same layout is palette exploration, not structural divergence.

Evaluate fit, comprehension, identity, accessibility, implementation cost and asset feasibility. Select and build; do not present endless concepts in place of delivering the requested interface. Preserve an established direction when exploration would only delay a focused correction.

## Common traps

An “anti-AI” checklist can become another template. Cream-and-serif, black-and-neon, broadsheet grids and minimal rounded cards can all become generic when applied indiscriminately. Do not ban them; explain why the selected treatment belongs to this product. Avoid permanent stylistic bans or requirements for motion, asymmetry, decorative labels or a fixed palette count.

Check the direction in a real narrow-screen composition and a difficult state, not only an ideal desktop hero. An art direction that collapses around long text or errors is unfinished.
